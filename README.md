# C++ Design Patterns Course

Practical C++ implementations of common design patterns. Each pattern is kept
in its own category and directory so examples can be read and compiled in
isolation.

## Creational patterns

- [Simple Factory](creational/SimpleFactory/README.md) - one factory chooses a
  compiler implementation from a requested type.
- [Factory Method](creational/FactoryMethod/README.md) - concrete notification
  factories create their matching product using modern C++ ownership
  (`std::unique_ptr`).
